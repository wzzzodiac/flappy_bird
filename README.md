# Flappy Bird — Bad Decisions Edition

A browser remake of the classic one-button obstacle game, styled like an engineering arcade terminal and equipped with a slightly disrespectful failure-analysis department.

## Features

- Canvas-based Flappy Bird gameplay
- Mouse / pointer and Space-key controls
- Normal and **Hardcore** difficulty
- Hardcore-specific pipe speed, gravity, gap size and death messages
- Multiple bird skins
- Optional synthesized sound effects using the Web Audio API
- Score milestones and medals
- Local best-score storage with `localStorage`
- Responsive layout for desktop and mobile

## Controls

- Click / tap the game area to flap.
- Press **Space** to flap from the keyboard.
- Use the difficulty toggle before a run.
- Choose a bird skin at any time outside the run.

## Tech

Plain HTML, CSS and JavaScript using a `<canvas>` element. No framework and no backend.
